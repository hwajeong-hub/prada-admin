- 범위: **눈에 보이는 결과만** 비교한다(색, 글자 크기·굵기, 크기, 간격, 그림자). 변수·텍스트 스타일 연결 여부, 컴포넌트 인스턴스 여부, 레이어 이름은 보지 않는다.

## 다르게 보이는 것

### 1. [중요] 테이블 헤더·셀 글자가 한 단계 큼 (13px → 12px)
- 화면: 헤더 13 Regular #555, 셀 13 Regular #333
- 문서: Table Header Cell · Table Cell 모두 Label 2 (12px)
- 색은 맞다. 크기만 다르다.

### 2. [중요] 페이지네이션 크기가 다름 (33.75 → 36)
- 화면: 번호 33.75×33.75, 간격 4.5, 현재 페이지만 36×36이라 선택 항목이 다른 항목보다 크다
- 문서: Pagination Item · Arrow 모두 36×36

### 3. [중요] 체크된 행에 선택 배경이 없음
- 화면: 8개 행이 체크됐지만 배경이 흰색
- 문서: 선택된 행은 Background/Selected (Navy `#1B2A41` 8%)

### 4. [사소] 체크박스 미선택 테두리 색이 두 가지
- 화면: 헤더 체크박스 #9E9E9E, 9·10행 체크박스 #CACDD8
- 같은 미선택 상태인데 색이 다르다. 문서에는 값이 없으니 하나로 정하고 문서에 적는다.

### 5. [사소] 테이블 헤더에 그림자
- 화면: 헤더 행에 0 2 5 5% 그림자
- 문서: Table에는 그림자가 없다

### 6. [사소] 일부 텍스트가 살짝 연함 (투명도 94%)
- 화면: `전체`, `50개씩 보기`, 검색 placeholder에 opacity 94%
- 문서 색(Gray 70 / Gray 50)보다 약간 연하게 보인다

### 7. [사소] Metric Card 아래 여백이 위보다 큼
- 화면: 위 24, 아래 36
- 36은 Spacing 스케일 밖의 값이다. 위아래를 24로 맞추거나 의도라면 문서에 적는다.

### 8. [사소] `50개씩 보기` Dropdown 너비 115
- 문서 Dropdown 기본 너비는 140이다. 의도된 축소라면 문제 없다.

### 9. [사소] `Go to page` 자간
- 화면: 자간 0
- 문서: 모든 텍스트 스타일 자간 -2%

### 10. [확인 필요] 사이드 메뉴 7개
- 문서상 PRADA는 8개(사용시간 설정 포함)다. 총판/대행사/광고주 권한이라 빠진 것이라면 정상이다.
