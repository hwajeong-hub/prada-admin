# LOGO & FAVICON MAKER

PRADA 디자인 시스템을 적용한 로고·파비콘 생성 도구입니다.

## 공개 사이트

https://prada-logo-favicon-maker.hwajeong0324.chatgpt.site

## 파일 관리

- `index.html`: 화면, 스타일, 로고 생성 및 저장 기능을 포함한 소스
- 별도 빌드 없이 브라우저에서 실행할 수 있습니다.
- ZIP 저장은 CDN의 JSZip 3.10.1을 사용합니다.

## 수정과 배포

GitHub에서 `index.html`을 수정한 후 기존 Sites 사이트에 해당 변경을 배포해야 공개 사이트에 반영됩니다. GitHub 커밋만으로 기존 Sites 주소에 자동 배포되지는 않습니다.

## 확인한 기능

- 1440px·360px 반응형 레이아웃
- SVG·PNG 및 전체 ZIP 저장
- 이름 복사 및 입력 유효성 검사

파비콘 SVG의 Figma 붙여넣기는 별도 확인이 필요합니다.
