## 공통 팁
- 텍스트를 바꾼 뒤 너비가 고정(Fixed)이면 **Auto width(↔)** 로 바꿔 주세요. 뱃지·라벨은 임시로 너비를 고정해 두었습니다.
- 본문용(Label 2/Regular)·제목용(Label 2/SemiBold) 텍스트 스타일은 이미 적용되어 있으니 글자만 바꾸면 됩니다.

## 8. 섹션 설명 한 줄 추가 (새 컴포넌트가 기존 섹션 안에 들어감)
| 섹션 | 추가할 문장 |
|---|---|
| Button | + Period Button: State(Default/Selected) — 기간 빠른 선택 (오늘·1일전·월) |
| Icon Button | + Table Icon Button: State(Default/Hover/Pressed) · Icon 스왑 — 테이블 셀 아이콘 액션 |
| Text Field | + Date Field: Status(Normal/Focus/Disabled) — Text Field + Icon/Calendar |
| Table Cell | + State(Default/Row Hover/Cell Hover) |
| Alert | + Layout(Slim/Detail) — Detail은 제목 + 본문 2줄, Radius/XL |
| Modal | + Dialog: 980 큰 팝업, 닫기 X, Confirm Button 속성 |
| Top Button | + Direction(Up/Down) |
